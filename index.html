Manual control

    

      

getgenv().FISHILIZER_NO_AUTORUN = true
local Fish = loadstring(game:HttpGetAsync(
    "https://civilation.github.io/Fishilizer/Fishilizer.lua"
))()
Fish.Init()

Fish.SaveGame("MyPlace")
Fish.SaveScripts(game, "ScriptsOnly")
Fish.SaveModels(game, "ModelsOnly")
Fish.Save(workspace.MyModel, "SingleModel")

    


    
Multiple hosts

    

      

local HOSTS = {
    "https://civilation.github.io/Fishilizer/Fishilizer.lua",
    "https://raw.githubusercontent.com/Civilation/Fishilizer/main/Fishilizer.lua",
}

local src
for _, url in ipairs(HOSTS) do
    local ok, body = pcall(game.HttpGetAsync, game, url)
    if ok and body and body:find("return", 1, true) then
        src = body
        break
    end
end
assert(src, "all hosts failed")
loadstring(src)()

    

  


  

    
API Reference

    
Fishilizer is designed to be highly modular and can be dropped into any internal script. All methods are exposed on the returned table.


    
Core Methods

    

      
SignatureDescription

      
Fish.Init()Initializes the environment. Resolves decompiler and bytecode functions from the executor. Returns the Fish table.

      
Fish.Save(instance, name?, opts?)Main entry point. Accepts `game`, a single Instance, or an array of Instances. Returns the serialized XML string.

      
Fish.SaveGame(name?, opts?)Shorthand for Fish.Save(game, ...).

      
Fish.SaveInstance(inst, name?, opts?)Forces `Mode = "full"`. Useful for isolating a single model.

      
Fish.SaveScripts(inst, name?, opts?)Forces `Mode = "scripts"` and enables `Decompile = true`.

      
Fish.SaveModels(inst, name?, opts?)Forces `Mode = "models"` and forces `Decompile = false`.

      
Fish.FetchClasses(cacheFile?)Fetches the official Roblox API Dump and merges new class property maps into memory. Useful for games using newly released instances.

    


    
Callbacks & Interception

    
Instead of writing directly to disk, you can intercept the XML string by passing a Callback function in the options table. This is useful for uploading to a webhook or processing the data internally.

    

      

getgenv().FISHILIZER_NO_AUTORUN = true
local Fish = loadstring(game:HttpGetAsync(
    "https://civilation.github.io/Fishilizer/Fishilizer.lua"
))()
Fish.Init()

local xml = Fish.Save(game, "Preview", {
    Callback = function(data)
        print("bytes: " .. #data)
        -- writefile("my_custom_path.rbxlx", data)
    end,
})

    


    
Advanced Injection

    
You can load specific parts of the engine without saving the whole game. For example, this script saves only the workspace lighting and terrain, ignoring all scripts and player characters.

    

      

getgenv().FISHILIZER_NO_AUTORUN = true
local Fish = loadstring(game:HttpGetAsync(
    "https://civilation.github.io/Fishilizer/Fishilizer.lua"
))()
Fish.Init()

Fish.Save({
    workspace,
    game:GetService("Lighting"),
    game:GetService("ReplicatedStorage")
}, "EnvironmentAndAssets", {
    Mode = "models",
    IgnoreDefaultProps = true
})
