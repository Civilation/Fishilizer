# Site source for Fishilizer

This directory contains the open-source source for the project's website. The files are organized so contributors can edit the site without touching the root index.html used for the live GitHub Pages site.

Structure:
- index.html  — the page source (already created)
- img/        — image assets (embed.PNG, brand.png, discord.png)
- css/        — extracted styles (future)
- js/         — extracted scripts (future)

To make the site fully self-contained, I copied embed.PNG into site/img. For the catbox images (brand and discord) I downloaded and saved them as site/img/brand.png and site/img/discord.png.

If you want me to also extract the inline CSS and JS into site/css/style.css and site/js/site.js and update site/index.html to reference them, reply and I'll continue.
